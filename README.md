纯静态单文件站点，无后端、无统计、无外部依赖；手机可「添加到主屏幕」，首次打开后断网也能看。

## 打开

- 在线：<https://你的用户名.github.io/康复知识库/>（仓库名若用中文，链接中的中文会被编码，建议仓库名用 `kfkb`）
- 深链示例：`#C1-9`（评定学第九章）、`#元zl-shenjing`（神经发育疗法详解）、`#证c107`（士资格证）、`#问脑卒中手功能怎么练`

## 更新方法

本仓库由本地生成器产出，请勿手改 `index.html`：

```bash
python 康复知识库-重建.py
python -c "import _web; _web.build_web()"
# 然后把 网页版/ 的四个文件复制到本仓库并提交
```

改了内容后把 `sw.js` 里的 `kfkb-v1` 递增为 `kfkb-v2`，避免访客看到旧缓存。
