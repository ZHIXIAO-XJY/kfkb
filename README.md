## 更新方法

`index.html` 由本地生成器产出，请勿手改：

```bash
python 康复知识库-重建.py
python -c "import _web; _web.build_web()"
# 把 网页版/ 下的 index.html、manifest.webmanifest、sw.js、icon.svg 复制到本仓库根目录
git add -A && git commit -m "更新" && git push
```

改了内容后把 `sw.js` 里的 `kfkb-v1` 递增为 `kfkb-v2`，避免访客看到旧缓存。
